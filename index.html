Definition
绑核就是限制进程、线程或中断只能在指定 CPU 范围内运行。
不绑核：CPU 0-383 都可能运行这个线程 绑核后：这个线程只能运行在 CPU 96-111

cache 是 CPU 附近的高速缓存

CPU 会自动缓存最近用过、或者附近可能马上用到的数据。线程迁移会降低复用概率。

什么数据会被缓存？

NUMA

NUMA 让 CPU、内存、设备有远近关系

线程跑在远端 NUMA，会增加内存访问和设备交互的延迟。

Preemption

绑核为什么能降低抢占概率？

它不会提高线程优先级，而是把关键线程和普通线程放到不同 CPU 区域，减少同一 CPU 上的竞争者。

不隔离：关键线程、日志线程、后台线程都可能挤到 CPU 10 隔离后：关键线程只在 CPU 0-15，后台线程尽量去别处
减少竞争者，而不是制造特权09
Trade-off

绑核不是越多越好

  • CPU 分得太少，关键线程会互相挤。
  • 绑到远端 NUMA，可能比不绑更差。
  • 误绑后台线程，可能破坏 runtime 自己的调度。
  • 忽略 cpuset/cgroup，会导致计划和真实环境不一致。
关键不是绑，而是绑到哪里10
Mental Model

专家级心智模型

隔离关键线程有稳定 CPU 区域。
亲和线程靠近内存和设备。
可控减少迁移、抢占和中断干扰。
CPU isolation + topology optimization11
Summary
绑核不是让线程神奇地变快，而是让关键线程跑得更稳定、更可控。

一句话 限制运行范围，换取更少迁移、更高 cache 复用、更低 NUMA 干扰和更少抢占。
